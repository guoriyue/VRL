# SPRINT: Qwen-Image-2.1 保留设计的文字替换 RL

状态：**planned**（2026-09-24）。接在物体移动 sprint 之后（该任务已放弃，见 SPRINT_qwen21_object_move_edit_rl §25）。

## 0. 一句话

用 GRPO（不做监督微调）让 Qwen-Image-2.1 学会**把图里某段文字换成指定的新文字**——招牌、海报、包装、屏幕——
新字要写对，旧字要没了，字体 / 材质 / 透视 / 光照和画面其余部分不变。

## 1. 为什么是这个任务（对照物体移动的教训）

| 物体移动的难点 | 文字替换 |
|---|---|
| 成功 = 擦 + 补 + 画三步同时成立，每步都没有干净的度量 | 目标是一个字符串：写对没写对，OCR 直接读（Levenshtein 距离是**连续**的，和 OCR sprint 一样能学） |
| "放上去了"靠家具框几何，框 ≠ 面 | 旧字有没有留下，也是 OCR 读；文字框由 OCR 给出，不用人工规则定位 |
| 背景项要覆盖整张图的小改动 | 只需保住文字框之外的区域（DINOv2 分块一致率 + 位移检查，物体移动里已验证：保住 vs 重画 AUC 1.0） |
| 7B VLM 数不清物体 | 判定不需要 VLM |
| 训练奖励曲线看不出学没学到 | OCR 那次同一配方 60 轮从 0.34 涨到 0.69，曲线是能看的 |

**已有基础**：OCR 奖励（PaddleOCR，`vrl/rewards/models/ocr.py`，`target_text` 的归一化编辑相似度）、OCR sprint 的单卡配方（学到了 +0.24）、
编辑评测（参考图、同噪声哈希、`--base-only`）、DINOv2 分块背景项。

## 2. 数据（RL 只需要源图 + 指令 + 元数据）

- **训练源图：模型自己生成**。用 OCR sprint 的那类提示词（招牌 / 海报 / 屏幕 / 包装上写着 "X"）让 base 生成，PaddleOCR 读出 X
  并给出文字框，只保留 OCR 读出的字和提示词一致的图（干净的源图 + 已知的旧字 + 框）。不受许可限制，数量不限，风格多样。
- **指令**：`Change the text "{X}" on the {sign/poster/screen/label} to "{Y}". Keep the font style, material, perspective, lighting and everything else exactly the same.`
  Y 从一个词表里选：和 X 长度相近（±30%）、字符集相同（全大写 / 首字母大写）、不是 X 的子串或超串；每张源图出 2 条不同的 Y。
  元数据：`text_edit = {source_text, target_text, text_box, surface}`。
- **held-out**：(a) 同源生成的 60 条（按提示词划分）；(b) **真实照片** 60 条：TextOCR / COCO-Text 里有清晰单段文字的照片，
  文字和框来自标注，指令同上——回答"在合成源图上学到的能力能不能迁移到真实照片"。训练不碰 (b)。
- 可行性检查：OCR 置信度 ≥ 0.9、文字框占画面 2–30%、单行；抽 30 条人工确认。

## 3. 奖励（全部包装现成模型，不写位置规则）

- **写对了 T**：PaddleOCR 读编辑图，`ocr` 键对 `target_text` 的归一化编辑相似度（连续，0–1）。
- **旧字没了 G**：编辑图的 OCR 结果里不再包含 `source_text`（1 / 0；X 与 Y 相似时按编辑距离折算）。
- **设计保住 P**：文字框（膨胀 10%）之外的 DINOv2 分块一致率 × 相位相关位移检查（复用 `object_move._background` 的实现）。
- `text_replace = T · G · P` 的几何平均；训练键 `text_replace_shaped = (text_replace + 0.2·P) / 1.2`（忠实但没改的输出有底分，避免 run1 式重画）。
- 可选诊断：文字框内的 DINOv2 相似度（字体 / 材质是否保住）——只记录不进奖励，等有标签再决定。

**GATE A（训练前，离线）**：40 张 base 输出 + 人造对照（原图不变、只擦旧字、写了错字、整图平移 3%、换场景、把 Y 贴在别处）——
正确替换必须排在所有对照之前；重复打分确定性。用 30 张人工标签核对 T/G/P 各自的判断。

## 4. 执行顺序与关卡

1. 源图生成 + OCR 过滤（GPU 约 1 h）→ 训练集 ≥ 600 条、held-out (a) 60 条；真实照片 held-out (b) 60 条（下载 + 标注核对）。
2. **base 关卡**：训练采样设置（512 / 10 步）下 48 条 × 4 张，base 成功率（OCR 全对且旧字没了）须落在 20–60%；同时盲判 80 张确认 OCR 判定可信。
3. GATE A。
4. dry run 3 轮 → 60 轮，每 10 轮存档（主机内存增长的教训），gpu_retry 包装；每 20 轮看一次 held-out（不是训练曲线）。
5. 判定：held-out (a)(b) base vs ck20/40/60，1024/40 同噪声：OCR 全对率、编辑相似度配对差（CI）、旧字残留率、设计保住率；
   盲评 61 条；对比页；镜头类回归检查。学会 / 持平 / 练坏。

## 5. 非目标 / 风险

- 不做监督微调；不手写位置规则（文字框来自 OCR）。
- 风险 1：base 成功率可能已经很高（OCR sprint 学完后的模型写字很稳）——用 **base 模型**而不是 OCR checkpoint 做起点，并选较难的 Y（长词、混合大小写）。
- 风险 2：模型把整块招牌重画（字对了但材质变了）——P 项管画面外，文字框内的材质靠诊断量观察，若普遍出现再加"框内 DINOv2 相似度"进奖励（需先验证）。
- 风险 3：PaddleOCR 对艺术字体误读——GATE A 里用人工标签量 OCR 的准确率；不够就换 TextPecker 类打分器（待测）。
